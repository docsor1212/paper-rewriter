# 密度阈值校准证据（calibration evidence）

## 阈值单一真源

五个密度信号（em-dash 过载/段落开头均匀化/「——」滥用/段落开头公式化/AI 高频软词堆叠）的阈值
**只存在于一处**：`scripts/hxt_core.py` 的 `DENSITY_THRESHOLDS` 常量表——评分器
`scan()` 与校准工具 `calibrate.py` 共用同一张表，不存在第二处字面量。改表即同时
改变运行时评分与校准报告，两者永不脱节。

## 校准方法与判据

- 语料按文件名前缀分组：`human_*` = 自然学术行文（含正当修辞密度：少量破折号、
  偶发框架副词开头）；`ai_*` = 模板腔行文（高密度信号）。
- **判据（机器可验）**：人稿语料不得以运行时同款条件（密度达标 AND 命中数达标）
  触发任何密度信号——触发即 `calibrate.py` exit 1。阈值以下不扣分的校准哲学
  （「阈值以下属于正常修辞区间」）由此变成可执行断言，不再是文档声明。
- 校准是**阈值合理性证据**，不是检测力声明：AI 稿语料为合成演示样例，不构成
  「能识别 AI 文本」的任何口径（见诚实边界：本工具不是检测器）。

## 复现命令

```bash
# 包内一键（随发布包分发，演示语料 references/calib_corpus/ 自带）
python scripts/calibrate.py            # exit 0 = 校准成立
python scripts/calibrate.py --json     # 机器可读（CI/agent 门禁）

# 开发仓库全量语料
python scripts/calibrate.py --corpus-dir tests

# 任意目录（按 ai_*/human_* 前缀分组）
python scripts/calibrate.py --corpus-dir 你的语料目录
```

## 口径提醒

- 演示语料为**合成句段**（本项目自写，用于展示校准方法与阈值分布），不代表
  任何真实稿件集合；各文件头部的数值是可复现实测，不是断言。
- 密度阈值只在**过载**时扣分：人稿含 1-2 处破折号、偶尔一段框架副词开头是正常
  修辞，校准判据保证这类文本不会被密度信号误伤。
- 阈值调整流程：改 `DENSITY_THRESHOLDS` → 跑 `calibrate.py`（人稿必须仍不触发）
  → 更新本表数值。人稿触发即说明新阈值过严，回炉。
